# ZeroGate --- Cybersecurity Library

> A categorized index of the books and technical references in this
> collection.

This README is a **navigation guide**: use the sections below to find
material by subject. The classification is based primarily on the
filenames in the supplied inventory, not a full review of every book's
contents.

## How to use this library

-   Start with the category that matches the skill you are studying.
-   Treat books with overlapping subjects as belonging to the category
    where they are most useful.
-   Check `99_Review_And_Duplicates` before keeping multiple copies or
    editions.
-   A title marked as a manual, cheatsheet, exam guide, report, or case
    study is a reference---not necessarily a textbook to read cover to
    cover.

## Book requests

Looking for a book that isn't in the library? Requests are welcome. You can:

-   Open a request in the repository's **Issues** tab (please include the
    title, author, and edition if possible), or
-   Message me directly on my **social media** (links in my profile).
